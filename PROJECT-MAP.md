# География проектов — сайт №2

Карта встроена в «Проекты», вход с главной — «География проектов». Данные:70 объектов из публичной GeoJSON-карты gorkiland.ru, извлечены18.10.2026. Состав и координаты сохранены;70 не означает70 парков. Локальный список — src/project-locations.json. Категория получена из наименования аттракциона.

Решение: светлая карта без рамки со свечением; лаймовые группы точек, тёмные отдельные точки, выделенный выбранный объект. На компьютере описание справа, на телефоне под картой. Поиск по тексту, фильтр типа, доступный выпадающий список всех результатов, возврат ко всей географии. Открытие выбранных координат в Яндекс Картах. Фотографии не приписываются неизвестным объектам: реальные фото/кейсы остаются отдельным разделом ниже карты.

Сохранены Onest и три размера текста. Данные не зависят от доступности внешней подложки. OpenStreetMap загружается при приближении блока к экрану; атрибуция видима. Колесо мыши прокручивает страницу, а не масштабирует карту. Мобильное перемещение включается кнопкой, которую можно отключить. При уменьшении движения отключены анимации карты.

Проверка:70 уникальных id и допустимые координаты; фильтр цепочных каруселей9; поиск «Тюмень»3; пустой результат и сброс; выбор объекта69 и быстрое переключение фильтров. Исправлена гонка отложенного приближения при замене точек: выбор выполняется без отложенного callback. Мобильные подложка/кнопки/карточка проверены; типографика12/16/40,95, без горизонтального переполнения. Сайт№1 не получает компонент карты.

Состав опубликованной карты не является свежим аудитом состояния эксплуатации каждого аттракциона. В английской версии сохранены исходные русские описания с явной подписью, переведены интерфейс и категории. Для полного англоязычного реестра требуется редактура названий/адресов, не машинная подмена первоисточника.
